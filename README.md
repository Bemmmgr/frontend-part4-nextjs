## Project Focus

This repository is used to collect Next.js-based frontend and full-stack projects.

The main goals are:

- Practice modern Next.js App Router development
- Build full-stack applications with database integration
- Strengthen TypeScript-based frontend architecture
- Practice authentication, form handling, validation, and testing
- Prepare portfolio-level projects for frontend and full-stack job applications
